# File Management System – Python GUI 🗂️ ![MIT License](https://img.shields.io/badge/license-MIT-green)

A user-friendly **Python-based GUI File Management System** built with **Tkinter**, designed to help users easily manage files and folders on their system. This project was developed as part of an Operating Systems Lab assignment and later extended with a graphical interface.

---

## 🔧 Features

This system supports the following **18+ operations** through a clean GUI:

- ✅ Create new files
- ✅ Create folders
- ✅ Rename files and folders
- ✅ Delete files and folders
- ✅ Move files or folders
- ✅ Copy files
- ✅ Search for files or folders
- ✅ Display file details
- ✅ Show folder contents
- ✅ Open files in default applications
- ✅ File sorting (by name, size, date)
- ✅ File extension filter
- ✅ File size filter
- ✅ Count number of files and folders
- ✅ Display system path
- ✅ Clear input/output fields
- ✅ Exit the app cleanly
- ✅ Error messages for invalid actions

---

## 🖥️ GUI Overview

The GUI is created using Python’s built-in **Tkinter** library, making it lightweight and OS-compatible (tested on Ubuntu). The main window includes:

- **Input field** for file/folder names
- **Output area** for operation results
- **Buttons** for each operation (18+)
- **Exit and Clear** functionality
